# 转诊资料最小交付

基层卫生院与县医院之间，按病种 / 风险制度和**用途**交换最小充分的转诊资料包：
基层医生逐项声明来源、采集时间、完整性与患者授权；系统只提示缺失与冲突，
不替临床人员判断病情；接收科室按职责解密、回执所见版本。

`fixtures/packet_manifest.json` 是一条脱敏业务样例（一次胸痛转诊从首版到
更正、撤回、到院复测、紧急升级的完整演进）。`src/referral_packet/contracts.py`
只冻结样例的七个顶层标识，其余合同在领域模块中定义。

## 模块地图

| 模块 | 职责 |
| --- | --- |
| `catalog.py` | 病种/风险最小条目规则、用途白名单、职责矩阵（制度版本化，无临床判断） |
| `manifest.py` | 逐项声明、缺失/冲突提示、版本哈希链（追加式，不可变） |
| `uploads.py` | 大文件分片上传：失败续传、哈希校验、内容寻址产物 |
| `journey.py` | 转诊旅程：业务键去重、幂等推送、交接事件时间线 |
| `envelope.py` | 按职责/用途绑定的加密封装（**流程仿真**，生产须替换 KMS） |
| `delivery.py` | 用途受限资料包、按职责解密、回执、超时同范围升级 |
| `audit.py` | 谁因何用途访问过哪些字段（含拒绝），患者可查 |
| `quality.py` | 双方质控：交接环节缺项定位；授权范围外不可浏览 |
| `service.py` | 用例门面 `ReferralPacketService` |

状态机与新增状态的迁移方式见 [`docs/state_model.md`](docs/state_model.md)。

## 关键不变量

- **最小交付**：资料包条目 = 清单有效条目 ∩ 用途白名单 ∩ 职责可见集 ∩ 已授权；
- **只提示不裁决**：缺失/无法取得不拦截紧急转诊，冲突由临床人员核实；
- **版本只追加**：更正、撤回（墓碑）、复测、升级均产生新 revision，
  `parent_hash` 成链，已签收版本冻结、继续可审计；
- **幂等**：`referral_key` 决定旅程唯一，`idempotency_key` 重放不产生新版本；
- **升级不扩权**：超时未读只按原范围催办（无合法承接职责时只记录升级事件）；
- **最小授权**：质控只能访问被指派的转诊，越权拒绝并留痕；患者只见本人记录。
